🏆 GameWithFun Leaderboard

Another feature of GameWithFun is its interactive player leaderboard. The leaderboard is powered by Firebase services and provides a recurring activity-based ranking for participating players.

Players can use Google Login to participate in the leaderboard. When a logged-in player starts a supported game through the GameWithFun website, the platform can record the game activity in the player's Firebase account.

The current leaderboard is primarily based on tracked total activity time, rather than individual game scores. Players with recorded activity during the active leaderboard period can be considered for the public ranking.

👤 Google Login

Google Login is used for players who want to participate in the GameWithFun leaderboard. Authentication allows the website to associate leaderboard activity with a specific Firebase user account.

A player record can contain information such as display name, profile image, games played, total tracked time, last game, online status, recent activity and the current leaderboard period.

Visitors who only want to browse and play the website's games can still use the main GameWithFun interface without treating the leaderboard as a requirement for ordinary game discovery.

⏱️ How Player Activity Is Tracked

When an authenticated player starts a supported game through GameWithFun, the website can record that game start. The player's gamesPlayed value can increase and the most recently started game can be stored.

The website also tracks visible activity time. The timer is designed to count time while the GameWithFun page is visible in the browser.

When the browser page becomes hidden, the current implementation stops counting that hidden-tab time. When the visitor returns to the GameWithFun page, activity tracking can continue again.

This means the leaderboard's time value is intended to represent tracked visible activity on the GameWithFun website rather than simply measuring how long a user has remained logged in.

📅 Leaderboard Periods

The GameWithFun leaderboard is divided into two periods during each month. The first period covers days 1 through 15, while the second period begins on day 16 and continues through the final day of the month.

The current leaderboard system uses the Asia/Riyadh time zone when determining the active period. When a new period begins, the relevant leaderboard activity values can be reset so that players begin the new period with a fresh activity record.

This recurring structure allows the leaderboard to provide a new activity cycle during each half of the month instead of maintaining one permanent ranking.

🥇 How the Leaderboard Rank Works

Eligible player records are collected for the current leaderboard period. Players need recorded game activity to be included in the public leaderboard.

The current system sorts eligible players according to total tracked time, from highest to lowest. If players have the same total tracked time, their names are used as a secondary sorting value.

The public leaderboard currently displays the first 25 eligible players. A logged-in player can also receive a personal rank display based on their position in the complete sorted list.
