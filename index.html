GameWithFun provides a Favorites feature for visitors who want quick access to games they like.

Favorites are separate from the Firebase leaderboard. A visitor does not need to use the leaderboard system simply to save a game as a favorite.

When the Favorites section is opened, GameWithFun checks the saved game IDs and displays the corresponding games. If no games have been selected, the website shows an empty Favorites message.

🏆 GameWithFun Live Leaderboard

One of the interactive features of GameWithFun is its Firebase-powered leaderboard. The leaderboard allows authenticated players to participate in a recurring ranking system based on tracked GameWithFun activity.

The current leaderboard system is different from a traditional game-score leaderboard. According to the current website code, players are ranked primarily according to their accumulated tracked total time.

A player must have tracked game activity during the current leaderboard period to appear in the public leaderboard. The system checks whether the player's gamesPlayed value is greater than zero.

The public leaderboard currently displays the top 25 eligible players. This creates a simple competitive area where players can see the current ranking of participating users.

👤 Google Login and Player Accounts

GameWithFun uses Firebase Authentication with Google Login for players who want to participate in the leaderboard system.

After a successful Google login, the website identifies the authenticated player and creates or updates a player record in the Firebase database.

The player record can contain information such as the player's display name, email address and profile image, together with leaderboard-related activity information.

When a player is logged in, the website can display the player's name and profile image. The login button is hidden and a logout option becomes available.

Logging out also triggers the website's activity-saving process before the Firebase authentication session is signed out.

🎮 What Happens When a Player Starts a Game?

GameWithFun has a game-start tracking function connected to the website's game cards.

When an authenticated player selects a supported game from a GameWithFun game card, the website first checks whether the player is logged in and whether the GameWithFun browser tab is visible.

When the tracking conditions are satisfied, the system increases the player's gamesPlayed value by one.

The system also records the ID of the most recently started game in the player's lastGame field. The player's online status, leaderboard period and last activity information are also updated.

After the tracking operation, the website can refresh the leaderboard before continuing to the selected game page.

📊 How Player Activity Connects to the Leaderboard

The leaderboard system stores player information inside the Firebase players collection. Each authenticated player has a database record associated with their Firebase user ID.

Several fields are important to the current leaderboard system.

  • gamesPlayed: tracked number of game starts during the current period.
  • totalTime: accumulated visible GameWithFun activity time in seconds.
  • lastGame: the ID of the most recently tracked game.
  • online: current online/activity state used by the leaderboard display.
  • lastActive: timestamp representing recent player activity.
  • leaderboardPeriod: identifies the leaderboard period associated with the player's data.

These values allow the website to maintain a player activity record and use the appropriate information when creating the current leaderboard.

⏱️ How Time Tracking Works

The current leaderboard system tracks time while the GameWithFun browser tab is visible.

The website starts a timer for an authenticated player when the player is actively viewing the GameWithFun page. The system periodically saves elapsed time to Firebase.

The tracking system specifically avoids counting time while the browser tab is hidden. When the player changes to another tab or leaves the GameWithFun page in a way that makes the document hidden, the system saves the visible activity time and stops the timer.

When the player returns to the GameWithFun tab, the website marks the player as online and starts a new visible-time tracking period.

This means the current leaderboard's time value is intended to represent tracked visible activity rather than simply the amount of time since a player logged in.

🏅 How the Rank Is Calculated

The current leaderboard first retrieves player records from Firebase and keeps players belonging to the current leaderboard period who have played at least one tracked game.

The players are then sorted by totalTime from highest to lowest.

If two players have the same total tracked time, their names are used as a secondary sorting value.

The first player in the sorted list receives rank number one, the next player receives rank number two, and so on.

The public leaderboard displays the first 25 players from this sorted list.

A logged-in player who has a valid position can also receive a private display showing their calculated rank, even if their position is outside the public top 25.

🏆 Leaderboard Periods

The GameWithFun leaderboard does not currently use one unlimited ranking period. Instead, the system divides each month into two leaderboard periods.

  • First period: Day 1 through Day 15
  • Second period: Day 16 through the final day of the month

The leaderboard period is calculated using the Asia/Riyadh time zone. This makes the leaderboard schedule consistent with Riyadh local time.

When a new period is detected, the system resets leaderboard activity values for the new period. Values such as gamesPlayed and totalTime are reset so that a new ranking period can begin.

The website also displays the current leaderboard period to users and indicates that the period ends at 11:59 PM.
