GAMEWITHFUN
===========

Files:
- index.html   Main website
- style.css    Design and responsive layout
- script.js    Games, search, categories and favorites

How to use:
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. Upload all three files to your web host/GitHub Pages.

To add your real games:
Open script.js and add a URL property to a game, then change playGame()
to open that URL. Replace the sample game names/art with your own games
and legally licensed thumbnails.
