🎮 Game With Fun Escape

Game With Fun Escape একটি মজার browser-based haunted house escape game। এই গেমে আপনার লক্ষ্য হলো রহস্যময় বাড়ির ভিতর থেকে নিরাপদে বের হয়ে আসা। গেম শুরু করার পর আপনাকে তিনটি লুকানো চাবি খুঁজে সংগ্রহ করতে হবে, পথের ভূতগুলো এড়িয়ে চলতে হবে এবং কয়েন সংগ্রহ করে নিজের স্কোর বাড়াতে হবে।

সবগুলো চাবি সংগ্রহ করার পর দরজার কাছে পৌঁছে Open Door বাটনে চাপুন। আপনি সফলভাবে দরজা খুলতে পারলে level complete হবে। গেমটি কোনো download বা installation ছাড়াই modern mobile এবং desktop browser-এ খেলা যায়।

How to Play Game With Fun Escape

  • ▶️ Start Game চাপুন।
  • 🗝️ তিনটি চাবি খুঁজে সংগ্রহ করুন।
  • 🪙 পথে থাকা কয়েন সংগ্রহ করুন।
  • 👻 ভূতের সঙ্গে ধাক্কা এড়িয়ে চলুন।
  • 🚪 তিনটি চাবি পাওয়ার পর দরজার কাছে যান।
  • 🎉 Open Door চাপুন এবং escape করুন।

Mobile Controls

মোবাইলে নিচের চারটি directional button ধরে রেখে character চালান। Desktop computer-এ Arrow Keys অথবা W, A, S, D ব্যবহার করেও character move করা যায়।

❓ Frequently Asked Questions

Game With Fun Escape কী?
Game With Fun Escape একটি free browser escape game যেখানে আপনাকে haunted house থেকে বের হওয়ার জন্য key সংগ্রহ করতে হবে এবং ghosts এড়িয়ে চলতে হবে।
এই গেম কি মোবাইলে খেলা যায়?
হ্যাঁ। গেমটি mobile touch controls-এর জন্য তৈরি করা হয়েছে। Android এবং অন্যান্য modern mobile browser-এ খেলা যায়।
গেমটি খেলতে কি download করতে হবে?
না। গেমটি browser-এর মধ্যেই চালানো যায়। আলাদা game application install করার প্রয়োজন নেই।
গেমে কয়টি key সংগ্রহ করতে হবে?
Escape করার জন্য মোট ৩টি key সংগ্রহ করতে হবে।
Ghost আমাকে ধরলে কী হবে?
Ghost আপনার character-এর খুব কাছে এলে current attempt reset হবে এবং আপনি আবার গেম শুরু করতে পারবেন।
গেমে sound effect আছে?
হ্যাঁ। গেমে browser Web Audio API ব্যবহার করে generated sound effects রয়েছে। কোনো external music বা sound file প্রয়োজন নেই।
