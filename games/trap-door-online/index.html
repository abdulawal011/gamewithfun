About Trap Door Online

Trap Door Online is a 3D multiplayer challenge where players take turns choosing doors on a platform. One door hides a trap. Make your choice, watch what happens, and try to be the player who stays safe.

You can create a private room and invite a friend with a room code, join a friend's room, or search for a random opponent. The game uses an online connection, so an active internet connection is required for multiplayer features.

How to Play

  1. Press Start the Game to open the game menu.
  2. Enter a nickname if you want to use one.
  3. Choose Random Match to find another player, or create a private room.
  4. To play with a friend, share your room code or enter the code your friend gives you.
  5. When the match is ready, take turns selecting a door and try to avoid the trap.
  6. Stay safe for as long as possible and aim to win the match.

Game Controls

Mouse / Touch

Drag to rotate the 3D view. Select a door by tapping or clicking it.

Zoom

Use pinch gestures on touchscreens or the mouse wheel / scroll to zoom.

Room Menu

Use the on-screen buttons to create, join, or leave a room.

Room Code

Copy and share the private room code with the friend you want to play with.

Tips for a Better Match

  • Make sure your internet connection is stable before joining a match.
  • Share the room code carefully so your friend can join the correct room.
  • Wait for the lobby to confirm that both players have joined.
  • On mobile, rotate your device to a comfortable position and use gentle drag movements.
  • Allow the 3D scene and character models a moment to load.

Frequently Asked Questions

Can I play with a friend?

Yes. Create a private room and share its room code with your friend. Your friend can enter the code using the Join Room option.

Can I play on a mobile phone?

Yes, on compatible mobile browsers with WebGL support. Touch gestures can be used to rotate and zoom the 3D view and select doors.

Why is the game not connecting?

Online matches require an internet connection and an available game server. If the server is waking up or temporarily unavailable, wait a moment and try again.
