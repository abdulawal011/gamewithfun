Game With Fun Color Sort

Game With Fun Color Sort is a free online color sorting puzzle game designed for players who enjoy relaxing and satisfying brain games. The objective is simple: move the colored balls between bottles and organize every color into its own bottle.

The game is built for modern web browsers and works on mobile phones, tablets and desktop computers. Its touch-friendly controls make it easy to pick up and move balls with a finger, while mouse controls can be used on desktop devices.

How to Play Color Sort

Select or drag the top ball from a bottle and move it into another bottle. A ball can only be placed where the move is allowed. The goal is to create bottles containing four balls of the same color.

Plan your moves carefully because an empty bottle can be very useful when you need extra space. Use the Undo button if you want to return to a previous position and try a different strategy.
